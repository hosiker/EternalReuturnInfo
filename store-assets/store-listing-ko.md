# Play 스토어 등록 정보 초안 (한국어)

Play Console → 앱 → **스토어 등록정보 → 기본 스토어 등록정보**에 옮겨 적습니다. 글자 수 제한은 Play 기준(앱 이름 30자, 간단한 설명 80자, 자세한 설명 4,000자)입니다.

> 님블뉴런 IP 문의 답이 오면 **앱 이름과 게임 이름 표기**를 그 답에 맞춰 고치세요. 답이 오기 전에는 아래 "기본안"처럼 게임 이름을 설명 문장에서만 쓰고, 공식 로고·게임 이미지는 어디에도 쓰지 않습니다.

## 앱 이름 (30자 이내)
- **기본안**: `ER info`  (7자)
- 대안(검색에 유리하지만 "공식 앱"으로 보일 위험이 커서, 문의 답 이후에 검토): `ER info - 전적 검색·듀오 찾기`

## 간단한 설명 (80자 이내)
```
이터널 리턴 팬을 위한 비공식 앱. 전적 검색, 듀오 찾기, 게시판, 채팅을 한곳에서.
```
(글자 수: 약 47자)

## 자세한 설명 (4,000자 이내)
```
ER info는 이터널 리턴을 즐기는 이용자를 위한 비공식 팬 앱입니다. 게임사(님블뉴런)와 관련이 없으며, 공식 서비스가 아닙니다.

■ 전적 검색
- 게임 닉네임으로 시즌별·모드별(랭크/일반, 솔로/듀오/스쿼드) 전적을 볼 수 있어요.
- 승률, 평균 순위, TOP 3 비율, 가장 많이 한 실험체와 최근 경기를 한눈에 확인해요.
- 내 전적 칩과 최근 검색 닉네임으로 빠르게 다시 찾아요.

■ 이번 주 무료 실험체와 게임 방송
- 무료로 사용할 수 있는 실험체를 홈에서 바로 확인해요.
- 공식 채널과 스트리머의 영상, 쇼츠를 종류별로 모아 보여 드려요. (영상은 YouTube로 연결됩니다)

■ 듀오 찾기
- 서버, 성별, 티어, 주로 하는 실험체를 등록하고 함께 할 사람을 찾아요.
- 등록한 사람의 승률과 최근 경기 요약을 카드로 확인하고, 바로 1:1 채팅을 시작해요.

■ 게시판과 채팅
- 질문, 공략, 일상 글을 올리고 댓글로 이야기를 나눠요.
- 제목과 내용으로 글을 검색해요.
- 1:1 채팅으로 메시지를 주고받아요. 안 읽은 메시지와 대화 시간을 확인할 수 있어요.

■ 안전한 커뮤니티
- 불쾌한 글·댓글·사용자를 신고하거나 차단할 수 있어요. 차단한 사용자의 글과 채팅은 보이지 않아요.
- 신고는 운영자가 확인해 처리해요. 이용약관과 커뮤니티 규칙은 앱의 설정에서 볼 수 있어요.
- 만 14세 이상만 가입할 수 있어요.

■ 개인정보
- 가입한 이메일과 닉네임만 저장하며, 광고와 결제는 없어요.
- 설정에서 언제든 회원 탈퇴로 계정과 데이터를 삭제할 수 있어요.

```

## 스크린샷 (휴대전화, 최소 2장·최대 8장)
**이니셜 아바타가 나오는 현재 빌드**로 찍으세요. 예전에 찍어 둔 화면에는 실험체 이미지가 있을 수 있어요. 게임 로고·게임 화면·실제 이용자 닉네임이 보이지 않게, 테스트 계정으로 찍으세요.
1. 홈(전적 검색 결과와 무료 실험체)
2. 전적 카드(시즌·모드 선택 후)
3. 듀오 찾기 목록
4. 게시판 목록
5. 게시글 상세와 댓글
6. 채팅
7. 프로필과 최근 전적
8. 설정(안전·정보 항목이 보이는 화면)
