# 님블뉴런 IP 사전 문의 답변 요약 (2026-11-26)

고객센터 문의(접수 번호 259175)에 대한 님블뉴런의 회신 요지입니다. 원문 전체가 아니라 우리가 지켜야 할 조건만 정리했습니다. 원문은 문의 접수 메일(받은편지함)에 있습니다.

## 1. 비공식 팬 앱 Google Play 배포: 가능
- 앱 안과 스토어 설명에 "님블뉴런과 무관한 비공식 팬 앱"임을 명확히 표기 (설정 화면, 로그인·시작 화면, 스토어 설명에 있음)
- 공식 서비스·제휴로 오인될 표현과 디자인 사용 금지
- 광고·결제·구독 등 수익화 요소를 넣기 전에 **사전 문의**
- Open API 이용 약관 준수
- 앱 기능 운영, 이용자 간 분쟁, 개인정보 처리 책임은 앱 운영자에게 있음

## 2. 팬키트 실험체 이미지: 가능 (조건부)
- 목적은 **실험체 구분을 위한 정보 표시**에 한정 (장식·배경 등으로 쓰지 않음). 이 용도에는 IP 정책 2.1의 창작성 기준을 적용하지 않음
- **자르기와 크기 조절만** 가능, 색상 변경·합성 등 다른 가공 금지
- **이미지 출처와 저작권 표기 필수** (설정 화면 하단, 스토어 설명에 표기)
- 앱에 포함하든 공식 주소에서 불러오든 가능

## 3. 앱 이름·아이콘의 "ER": 가능
- 자체 제작 문자형 로고는 사용 가능. 공식 로고·게임 아이콘과 유사하거나 공식으로 오인될 디자인은 금지

## 4. 실험체 이름 표시: 가능
- 전적·목록 등 정보 표시 목적. 공식 명칭을 임의로 바꾸거나 가공하지 않고 사용

## 5. 공식 공지·영상 썸네일: 가능
- 제목·요약·썸네일을 **원본 그대로** 표시하고 공식 페이지·영상으로 연결. 이미지 수정과 원문 전체 복제는 삼감

## 6. Google Play 스토어 등록 이미지: 가능 (조건부)
- 위 기준을 지킨 앱 화면의 스크린샷은 사용 가능
- 공식 로고와 키 아트의 **별도 사용**, 공식으로 오인될 이미지 사용은 제한

## 공통
- 정책 위반이 확인되면 수정 또는 배포 중단을 요청받을 수 있음. 그 외는 님블뉴런 IP 이용 정책(2026.10.22) 참고
