# Google Play 「데이터 보안」 양식 답안 (ER info, 2026-11-09 기준)

Play Console → 앱 → **정책 및 프로그램 → 앱 콘텐츠 → 데이터 보안**에 옮겨 적는 답안입니다.
근거는 앱 코드, `docs/privacy-policy.md`, 그리고 Firebase 공식 안내(https://firebase.google.com/docs/android/play-data-disclosure)입니다.
Firebase 쪽 분류는 이 안내를 그대로 따랐고, 최종 책임은 개발자에게 있다고 안내돼 있으니 제출 전에 한 번 더 확인하세요.

> 개인정보처리방침과 내용이 달라지면 안 됩니다. 이 답안을 쓰기 전에 방침 수정(PR)을 먼저 머지하세요.

---

## 1. 첫 화면 질문

| 질문 | 답 |
|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** |
| 수집하는 모든 사용자 데이터가 전송 중 암호화되나요? | **예** (HTTPS만 사용, 평문 통신 차단 `usesCleartextTraffic=false`) |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **예** — 앱 안(프로필 > 설정 > 회원 탈퇴) + 웹 주소 `https://hosiker.github.io/EternalReuturnInfo/account-deletion` |

## 2. 데이터 유형별 답 (표에 없는 유형은 모두 "수집 안 함")

공통: **임시 처리(ephemeral) 아니요**(서버에 저장됨), **서비스 제공자(Firebase)로 보내는 것은 "공유"가 아님**(Firebase 안내: 개발자 지시에 따라 처리하는 하위 처리자 외 제3자에게 전달하지 않음).

| Play 분류 > 유형 | 수집 | 공유 | 필수/선택 | 목적 | 앱에서 쓰는 곳 |
|---|---|---|---|---|---|
| 개인 정보 > **이름** | 예 | **예**(아래 4번 판단 항목) | 필수 | 앱 기능, 계정 관리 | 닉네임. 게임 전적 조회 시 닉네임이 게임 공식 API로 전달 |
| 개인 정보 > **이메일 주소** | 예 | 아니요 | 필수 | 계정 관리, 앱 기능 | 가입·로그인·비밀번호 재설정 |
| 개인 정보 > **사용자 ID** | 예 | 아니요 | 필수 | 앱 기능, 계정 관리, 사기 방지·보안·규정 준수 | Firebase uid(글·댓글·채팅·차단·신고에 쓰임) |
| 개인 정보 > **기타 정보** | 예 | 아니요 | **선택** | 앱 기능 | 듀오 찾기 등록 시 성별·서버·티어·모스트 실험체·승률·평균 순위·최근 5경기 순위, 선택한 실험체 |
| 메시지 > **기타 인앱 메시지** | 예 | 아니요 | **선택** | 앱 기능 | 1:1 채팅(내용, 보낸·받는 사람, 시간, 읽음 여부) |
| 앱 활동 > **기타 사용자 생성 콘텐츠** | 예 | 아니요 | **선택** | 앱 기능, 사기 방지·보안·규정 준수 | 게시글, 댓글, 이용자 신고 내용 |
| 기기 또는 기타 ID | 예 | 아니요 | 필수 | 앱 기능, 사기 방지·보안·규정 준수 | Firebase가 자동으로 만드는 앱 설치 식별자(FID) — Google 정의에서 "기기 또는 기타 ID" 예시에 포함 |

수집하지 않는 것(모두 "아니요"): 위치, 금융 정보, 건강·피트니스, 연락처, 사진·동영상, 오디오, 파일·문서, 캘린더, 웹 검색 기록, 앱 상호작용(분석), 앱 정보·성능(비정상 종료 로그·진단).
- 홈 전적 검색의 최근 검색어, 자동 로그인 기록, 약관 동의 기록, 영상 목록 임시 저장은 **기기 안에만 저장**되고 서버로 가지 않으므로 수집이 아닙니다.
- Firebase Analytics는 앱에서 끄고 쓰지 않습니다. 광고·분석·비정상 종료 수집 SDK는 없습니다.

## 3. 보안 관행 화면

| 질문 | 답 |
|---|---|
| 전송 중 암호화 | **예** |
| 데이터 삭제 요청 방법 | **예** (앱 안 + 웹 주소) |
| 삭제 범위 안내(입력칸에 적을 문구) | 계정 삭제 시 이메일·닉네임·프로필·듀오 정보·글·댓글·내 채팅 기록 삭제. 다른 이용자의 신고가 접수된 글·댓글은 신고 처리를 위해 3개월 보관 후 삭제. 상대방 대화 기록에는 메시지가 남을 수 있으나 "탈퇴한 사용자"로 표시 |
| 독립적 보안 검토 | **아니요** |
| Families 정책 준수 약속 | **아니요** (만 14세 이상 서비스) |

## 4. 제가 판단이 필요했던 항목 (결정해 주세요)

1. **닉네임을 "공유"로 표시할지** — 추천: **예(공유)**.
   - 이유: 전적 조회 때 이용자가 입력한 닉네임이 게임 제작사 API 서버로 전달됩니다. "서비스 제공자" 예외로 볼 여지가 있지만, 제출 후 "공유 누락"으로 반려되는 위험이 더 큽니다. 공유로 적어도 앱 사용에는 영향이 없습니다.
2. **"기기 또는 기타 ID"를 적을지** — 추천: **적기**.
   - 이유: Firebase 안내에 FID("이용자나 기기를 직접 특정하지 않는다"고 설명)가 자동 수집으로 나와 있고, Google의 유형 정의가 FID를 예로 들고 있습니다. 적었다고 불이익은 없고 빠뜨리면 불일치입니다.
3. **채팅·글·듀오 정보를 "선택"으로 둘지** — 추천: **선택**. 가입과 로그인에 필요한 이메일·닉네임·사용자 ID만 "필수"입니다.

## 5. 같이 입력하는 다른 앱 콘텐츠 항목

| 항목 | 추천 답 |
|---|---|
| 광고 포함 여부 | 아니요 |
| 광고 ID 사용 | 아니요 — 제출 전에 Android Studio의 **Merged Manifest**에서 `AD_ID` 권한이 없는지 확인 |
| 대상 연령 | **16~17세, 18세 이상**만 선택 (만 14세 미만 가입 불가이고, "13~15세"를 고르면 13세가 대상이라는 뜻이 되어 개인정보처리방침과 어긋남) |
| 사용자 생성 콘텐츠(UGC) | 예 — 신고·차단 기능 있음(앱 안), 이용약관 있음, 운영 절차 문서 있음 |
| 콘텐츠 등급 설문 | UGC 예, 사용자 간 소통 예, 위치 공유 아니요, 구매 아니요 |
| 데이터 삭제 | 앱 안 삭제 + 웹 삭제 안내 주소 입력 |
| 정부·금융·건강·뉴스 앱 여부 | 모두 아니요 |
| 테스트 계정(앱 액세스 정보) | 검토용 로그인 계정을 하나 만들어 아이디·비밀번호 제공 (로그인이 필요한 앱) |

## 6. 이 답안이 바뀌어야 하는 경우

- 광고·결제·구독을 넣을 때 (구매 기록, 광고 ID 등이 추가됨)
- Firebase Analytics나 비정상 종료 수집(Crashlytics)을 켤 때
- 이용자 사진 업로드를 다시 지원할 때(사진 유형 추가)
- 새 외부 서비스로 이용자 정보를 보낼 때
