# ER info 계정 및 데이터 삭제 안내

ER info(이하 "앱")의 계정과 데이터를 삭제하는 방법을 안내합니다.
삭제된 정보의 처리 기준은 [개인정보처리방침](privacy-policy)과 같습니다.

## 방법 1. 앱에서 직접 삭제 (권장)

1. 앱에 로그인합니다.
2. 하단 탭에서 **프로필**을 엽니다.
3. 화면 오른쪽 위의 설정(⚙) 버튼을 눌러 설정 화면 맨 아래의 **회원 탈퇴**를 선택합니다.
4. 안내 창에서 **탈퇴하기**를 누릅니다.
   - 보안을 위해 마지막 로그인으로부터 시간이 지났다면 다시 로그인하라는 안내가 나올 수 있습니다. 다시 로그인한 뒤 탈퇴를 진행하세요.

## 방법 2. 이메일로 삭제 요청

앱에 로그인할 수 없거나(비밀번호 분실, 앱 삭제 등) 앱에서 처리되지 않는 경우 이메일로 요청할 수 있습니다.

- 받는 주소: erinfomanager@gmail.com
- 제목: `[ER info] 계정 삭제 요청`
- 본문에 적어 주실 내용: 가입한 이메일 주소, 앱에서 쓰는 닉네임
- 본인 확인을 위해 **가입한 이메일 주소에서 보내 주세요.** 다른 주소로 보내신 경우 가입 이메일로 확인 메일을 다시 보낼 수 있습니다.
- 확인 후 지체 없이 삭제하고 결과를 회신합니다.

## 삭제되는 정보

- 이메일 주소와 로그인 정보(Firebase Authentication 계정)
- 닉네임, 선택한 실험체(캐릭터), 프로필 정보, 듀오 찾기 정보
- 내가 쓴 게시글과 댓글
- 내 대화 기록(내 쪽에 저장된 채팅방)

## 삭제 후에도 남는 정보와 보관 기간

- **다른 이용자의 신고가 접수된 게시글·댓글**: 부정 이용 확인을 위해 첫 신고 접수일로부터 **3개월간** 보관한 뒤 삭제합니다. 작성자는 "탈퇴한 사용자"로 표시되며 닉네임 등은 남지 않습니다.
- **상대방의 대화 기록**: 상대방 화면에 주고받은 메시지가 남을 수 있으며, "탈퇴한 사용자입니다."로 표시되고 더 이상 메시지를 보낼 수 없습니다.
- **신고 내역**: 신고자 식별 번호와 접수 시각만 처리 기록으로 보관됩니다.
- **탈퇴 표시**: 이용자 식별 번호(uid)와 "탈퇴한 사용자"라는 표시만 남습니다.
- 관계 법령에 따라 보관해야 하는 정보는 해당 기간 동안 보관합니다.

탈퇴한 닉네임은 삭제 즉시 다른 이용자(또는 본인의 새 계정)가 다시 사용할 수 있습니다.
삭제된 계정과 데이터는 복구할 수 없습니다.
